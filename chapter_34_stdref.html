QCBook

STDRef

Currently, the standard library is rather small, with only 14 namespaces.

  1. CoreConcepts. This contains concepts for everything else to use, those being Eq (operator==), and Allocated (_destroy).
  2. AdvQBool. Random boolean.
  3. Array. A constant-size array.
  4. Vector. A dynamic array.
  5. List. A linked list.
  6. Utils. Basic utility functions.
  7. Math. Math intrinsics.
  8. OSInterop. Operating-system interaction.
  9. Pair. Pair of 2 items.
  10. Optional. Optional value.
  11. Span. Like an array, but does not own the memory.
  12. Encodings. Base64, Hex, and URL encodings.
  13. Unordered. Hash-based Map and Set.
  14. Filesystem. Filesystem functionality similar to C++ std::filesystem.

concept Eq {
    1_of {
        bool operator==(Self other);
        bool operator==(Self self, Self other);
    }

    at_least 1_of {
        void _destroy();
        void _destroy(Self self);
    }
