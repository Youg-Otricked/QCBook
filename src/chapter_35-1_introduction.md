# Final Project 1: Introduction

Before we start coding, here's a little goal of this project and all final projects structure:

- To get you coding in the language.
- To get you to learn & make some things from core first principles.
- To let you work out the language a bit.

This project will have you built a P2P communication app that works across the internet.

## Structure

All final projects will be structured like this:

A series of lessons making the core fundamental versions, each branching off eachother.
Bonus lessons branching off the finished project.
A final bonus for if you finished the first bonuses.
