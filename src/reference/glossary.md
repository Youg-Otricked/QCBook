# Glossary

IR
: Intermediate Representation

Intermediate Representation
: A simplified version of assembly that compiles down to every other os target.

AST
: Abstract Syntax Tree

Abstract Syntax Tree
: A tree the parser generates as a logic flow of your code.

symbols
: The names of things in your program

symbol
: A name in your program

file descriptor
: How the operating system keeps track of files

file pointer
: Position for reading & writing in a file

enum index
: Position in the enum starting from 0 in order of definition

usertype
: A type defined by the user
