# Final Project 1: Roadmap

The remaining versions of this project will be in this order:

- Version 2: Real time communication, instead of taking turns.
- Version 3: Missed Message Queue, for if the other person sends a message while you are typing.
- Version 4: Heap-Allocated messages, for >1024 char messages, and a from-principles length-header passing system.
- Version 5 (bonus 1): Many people!
- Version 6 (bonus 2): Implement TLS-style password handshake from principles.
- Version 7 (bonus 3): Add commands & usernames.
